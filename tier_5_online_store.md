# Tier 5 – Architecture Challenge: Explain the Whole System

## Project: The Online Store

### 1. Introduction

An online store is a computer system that allows customers to select products, place orders, make payments, and receive order confirmations.

The system uses customer input, program instructions, data processing, storage, and output to complete the order.

### 2. Customer Input

The customer provides information to the online store.

Examples include:

- Product selected.
- Quantity required.
- Customer name.
- Delivery address.
- Payment information.

This information is called input data because it enters the computer system.

### 3. Application / Program

The online store application receives the customer's information.

The program contains instructions that tell the computer how to handle the information and process the customer's order.

For example, the application allows the customer to select a product, enter a quantity, and submit an order.

### 4. Instructions

The program gives the computer specific instructions to execute.

These instructions include:

1. Identify the selected product.
2. Check whether the product is available.
3. Check whether the requested quantity is available.
4. Calculate the total order price.
5. Validate the customer's information.
6. Process the payment securely.
7. Save the order information.
8. Update the product inventory.
9. Generate an order confirmation.

### 5. Data Processing

The computer processes the customer's information according to the program instructions.

For example:

**Product price:** 50,000

**Quantity:** 2

**Calculation:**

50,000 × 2 = 100,000

**Order total:** 100,000

The computer uses the input data and performs calculations to produce new information.

### 6. Stored Data

After processing the order, the system stores relevant information in a database.

For example:

| Information | Stored Value |
|---|---|
| Customer | Victor |
| Product | Laptop |
| Quantity | 2 |
| Product price | 50,000 |
| Order amount | 100,000 |
| Order status | Confirmed |

The database allows the online store to remember the customer's order and retrieve the information later.

Payment information must be handled securely and sensitive payment details should not be stored unnecessarily.

### 7. Result / Output

After the order has been processed successfully, the system provides feedback to the customer.

Example:

```text
ORDER CONFIRMED
-------------------------
Customer: Victor
Product: Laptop
Quantity: 2
Total: 100,000

Your order has been placed successfully.
Thank you for shopping with us!
```

This confirmation is the output produced by the computer system.

### 8. Final Challenge: Explain the Whole System

The complete process follows this sequence:

```text
Customer
    ↓
Customer Input
    ↓
Application / Program
    ↓
Instructions
    ↓
Data Processing
    ↓
Stored Data
    ↓
Result / Output
```

**What is the computer doing?**

The computer receives information, follows instructions, processes data, stores relevant information, and produces results.

**What is the program doing?**

The program provides instructions that tell the computer how to handle the customer's order.

**What data is involved?**

The data includes the customer's name, selected product, quantity, delivery information, payment information, product price, and order status.

**What instructions are being executed?**

The computer identifies the product, checks availability, calculates the total price, validates information, processes payment, stores the order, and generates confirmation.

**What is the output?**

The output is the order confirmation showing that the customer's order was successfully placed, including the order details and total amount.

**What information must be stored?**

The system needs to store the customer details required for the order, product information, quantity, order amount, payment status, delivery information, and order status.

### 9. Capstone Mental Model

The major concepts from this section connect as follows:

```text
REAL-WORLD PROBLEM
        ↓
       DATA
        ↓
     PROGRAM
        ↓
   INSTRUCTIONS
        ↓
    PROCESSING
        ↓
   STORED DATA
        ↓
      OUTPUT
```

A computer does not automatically know how to solve a real-world problem.

Someone must:

1. Identify the problem.
2. Determine the data required.
3. Design a sequence of instructions.
4. Translate those instructions into a program.
5. Allow the computer to process the data.
6. Store information when necessary.
7. Produce a useful result.

### 10. Final Reflection

**Question: Explain this statement in your own words.**

"A computer does not understand the real world directly. It works with representations of information and follows instructions for processing those representations."

**My Answer:**

A computer cannot understand real-world situations in the same way humans do. It needs information to be converted into data that it can recognize and process.

A programmer must provide clear instructions that explain what the computer should do with the information.

The computer then follows those instructions, performs calculations or other operations, stores information when necessary, and produces an output.

For example, when a customer orders a product online, the computer does not simply understand that the customer wants to buy something. The program receives the product details, checks availability, calculates the price, processes the order, stores the information, and displays a confirmation.

This shows that computers depend on data and instructions to perform tasks correctly.
